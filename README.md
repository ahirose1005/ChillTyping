# ChillTyping

タイピングでコインを集め、家具を購入して部屋を育てるローカルWebゲームです。

## 起動方法

Python 3 が使える環境で、このディレクトリから次を実行します。

```powershell
python -m http.server 8000
```

ブラウザで <http://localhost:8000> を開いてください。

Node.js がある場合は、代わりに次でも起動できます。

```powershell
npx serve .
```

## 遊び方

- 表示された英文を正しくタイプすると、1文字ごとにコインを獲得します。
- 20コンボごとに追加コイン、文章の完成時にボーナスコインを獲得します。
- ヘッダーの「ショップ」から専用画面へ移動できます。
- 「部屋・壁紙・床・家具・家電・装飾」のタブからアイテムを購入できます。
- 壁紙・床・部屋タイプは、購入後もショップから自由に切り替えられます。
- 購入した家具・家電・装飾はインベントリへ入り、好きなものだけを部屋に配置できます。
- 配置したアイテムは部屋内でドラッグして、好きな位置へ移動できます。
- タイピングやコレクションの実績を達成すると、専用通知と記念の額縁を獲得できます。
- 獲得した実績の額縁もインベントリへ入り、好きな位置へ配置できます。
- コインと購入状況はブラウザの `localStorage` に自動保存されます。
- `Enter` キーまたは「次の文章」で文章をスキップできます。

外部ライブラリやビルドは不要です。Google Fontsへ接続できない場合も、システムフォントで遊べます。
